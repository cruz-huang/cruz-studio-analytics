隐私政策 Privacy Policy

更新日期：2026-11-09

  • 本程序只请求两个只读权限：YouTube Analytics（yt-analytics.readonly）和 YouTube Data（youtube.readonly）。它不能上传、修改或删除任何内容。
  • 读取的只有频道所有者本人频道的数据：播放、观看时长、留存、流量来源、公开评论等。
  • 数据只保存在频道所有者自己的电脑上，用于自己复盘。不出售、不分享给任何第三方，不用于广告。
  • 授权凭证只保存在所有者电脑本地。随时可以在 Google 账号权限页 撤销授权。
  • 本程序对 Google API 数据的使用遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

This app requests read-only access (yt-analytics.readonly, youtube.readonly) to the owner's own YouTube channel. Data is stored only on the owner's computer for personal review, is never sold or shared with third parties, and is not used for advertising. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
